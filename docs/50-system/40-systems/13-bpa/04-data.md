# BPA Standard Governance — Data

| Item | Location |
|---|---|
| clauses, schemas, grammars | `bpa-standard/spec/` |
| vectors | `bpa-standard/vectors/<profile>/VER-CONF-nnnn.json` |
| formal models | `ubos-verify/models/` |
| change proposals | `bpa-standard/proposals/NNNN-title.md` with status |
| errata | `bpa-standard/errata/` |
| extension registry | `bpa-standard/registry/extensions.json` (signed per release) |
| algorithm registry | `bpa-standard/registry/algorithms.json` |
| certificate registry | public site backed by signed DAT-Certificate files |
